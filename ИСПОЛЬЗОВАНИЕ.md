# Использование для любой Google Таблицы (полный цикл)

Пошаговое руководство: как подключить ИИ-копилот к **любой** Google Таблице и
пользоваться им в полном объёме (План → Превью → Применение → Откат).

Серверная часть уже реализована и проверена живым циклом (см. ниже «Статус»).
Клиент — это надстройка Google Apps Script (`apps-script/`), которая ставится
в таблицу один раз.

---

## Что нужно (один раз)

1. **Бэкенд доступен по URL** (таблица не может дотянуться до `localhost`).
   Варианты:
   - **Локально для теста:** пробросить порт наружу — `ngrok http 8022` или
     Tailscale Serve (у тебя уже настроен Tailscale). Получишь `https://xxx.tailxxxxx.ts.net`.
   - **Для команды:** задеплоить бэкенд на сервер (Docker/uvicorn) за HTTPS.
2. **Google-аккаунт** с доступом к таблице (для деплоя надстройки через clasp).
3. **Хотя бы один LLM-провайдер**: `fake` (всегда работает, для демо) или
   `hermes`/OpenAI с ключом.

---

## Шаг 1. Запуск бэкенда

```bash
cd backend
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[test]"
cp .env.example .env
# в .env: HERMES_ENABLED, HERMES_BASE_URL, HERMES_API_KEY, ENABLED_PROVIDER_TARGETS=fake,hermes
uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8022
```

Проверка: `curl https://<твой-url>/health/live` → `{"status":"ok"}`.

## Шаг 2. Деплой клиента в таблицу (clasp)

```bash
cd apps-script
npx clasp login            # откроется браузер Google — авторизуйся
npx clasp create --type sheets --title "Spreadsheet AI Agent"
# или привяжи к существующему проекту: npx clasp clone <SCRIPT_ID>
```

В `appsscript.json` уже прописаны нужные scopes. Открой `Code.gs` и укажи URL
бэкенда (константа `BACKEND_BASE`) и, при необходимости, токен пилота.

```bash
npx clasp push
```

В таблице: **Расширения → Apps Script → запустить `onOpen`**, обнови таблицу.
Появится меню **Spreadsheet AI Agent → Open Assistant**.

## Шаг 3. Пользование (для любой таблицы)

1. Открой боковую панель (**Spreadsheet AI Agent → Open Assistant**).
2. **Выдели диапазон** в листе (например, пустые `I5:I7`).
3. Напиши запрос в чат, например: «заполни выделенное ценами 0.1, 0.2, 0.3».
4. Получи **Превью плана**: какие ячейки изменятся, предупреждения, затронутые
   ячейки. Формулы вне цели не трогаются.
5. Нажми **Approve** (подтверждение), затем **Apply** — изменения применяются
   только после явного нажатия.
6. Если нужно отменить — **Undo** (откат по снимку, локальный и точный).

### Что умеет (P0-инструменты)
- `NO_OP` — только ответ/анализ без записи.
- `SET_VALUES` — записать значения.
- `SET_FORMULAS` — записать формулы (начинаются с `=`).
- `CLEAR_RANGE` — очистить диапазон.
- `FORMAT_RANGE` — форматирование.
- `ADD_SHEET` — добавить лист (без изменения ячеек).

---

## Безопасность (важно)
- Модель **не пишет код** в таблицу — только разрешённые структурированные действия.
- **Apply только после явного подтверждения**; токен подписан и с истечением срока.
- **Снимок снимается до применения** → Undo локален, детерминированный.
- Защищённые и объединённые (merged) диапазоны — запись в них **запрещена**.
- Секреты провайдеров — только на сервере; клиент их не видит.

## Если бэкенд недоступен из таблицы
Google Apps Script требует HTTPS и публичный URL. Локальный `localhost` не
сработает. Используй:
- `ngrok http 8022` (быстро, для теста),
- или Tailscale Serve (у тебя уже настроен: `https://rostislavs-macbook-pro.tailc9f767.ts.net/`),
- или задеплой бэкенд на сервер/VPS за HTTPS.

В `Code.gs` (Apps Script) укажи именно этот внешний URL в `BACKEND_BASE`.
