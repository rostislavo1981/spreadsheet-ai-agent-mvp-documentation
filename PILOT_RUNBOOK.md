# Пилотный runbook — MVP «ИИ-агент для таблиц»

Руководство по запуску пилота для ограниченной группы пользователей на
нечувствительной копии таблицы. Соответствует Фазе 5 (закалка пилота).

## Что уже реализовано и протестировано
- 🟢 План → Превью → явное Применение с подписанным токеном одобрения.
- 🟢 Откат по снимку (snapshot-derived undo), локальный и детерминированный.
- 🟢 SQLite-аудит (переживает перезапуск), очищенный от сырых данных.
- 🟢 Защита защищённых и объединённых (merged) диапазонов.
- 🟢 Скан на prompt-инъекции (fail-closed → 422).
- 🟢 Ограничение частоты (rate limit, 429) и жёсткие потолки.
- 🟢 Резерв маршрутизации провайдеров (Hermes → fake при сбое).

## Предварительные условия
1. Python 3.12+, `pip install -e ".[test]"`.
2. Хотя бы один провайдер: `fake` (всегда) или `hermes` с валидным ключом.
3. Таблица-копия без чувствительных данных для пилота.

## Запуск бэкенда
```bash
cd backend
cp .env.example .env
# заполнить: HERMES_ENABLED, HERMES_BASE_URL, HERMES_API_KEY, ENABLED_PROVIDER_TARGETS
uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
```
Проверка: `curl http://127.0.0.1:8000/health/live` → 200; `/v1/capabilities` → список инструментов.

## Подключение клиента
См. `apps-script/README.md` (деплой через clasp). Токен пилота — в User Properties,
не в коде. Без токена `/v1/runs:plan` вернёт 401.

## Сценарий приёмки (P0)
Для каждого пункта ACCEPTANCE_CRITERIA.md, помеченного **P0**:
1. Выделить диапазон в копии таблицы → запросить правку.
2. Проверить превью: затронутые ячейки, предупреждения, сохранение формул вне цели.
3. Применить → проверить, что запись произошла только после явного нажатия.
4. Изменить лист вручную (сбить fingerprint) → повторить Применение → должно быть отклонено (stale).
5. Откатить последний прогон → состояние возвращается к снимку.
6. Отключить Hermes (нет ключа) → план всё равно строится через резерв.

## Наблюдаемость
- `GET /v1/metrics` — санитизированные счётчики (прогоны, применения, сбои, ячейки, по провайдерам).
  Не содержит содержимого ячеек, промптов или отпечатков.
- `GET /v1/audit` — очищенный журнал прогонов.

## Откат и хранение данных
- Откат клиента локален (snapshot до применения); сервер хранит только метаданные аудита.
- Хранение аудита ограничено `AUDIT_RETENTION_DAYS` (по умолчанию 30), размер БД — `SQLITE_DB_PATH`.
- Для полного сброса: удалить файл SQLite (прогоны/аудит), клиентские снимки не затрагиваются.

## Известные ограничения (вне scope MVP)
- Живая развёртка Apps Script требует Google OAuth + clasp (выполняется вручную).
- Реальные вызовы OpenAI/OpenRouter/Hermes в CI не выполняются (только fake + мок Hermes).
- Нет асинхронной очереди, мультитенантной авторизации, экспорта телеметрии.
