## Safety invariants (all enforced / tested)
- Read auto; write only on explicit Apply with signed, expiring approval token.
- Only allowlisted P0 actions; model output untrusted + schema-validated (1 repair).
- Selection-first bounded context; formulas preserved; snapshot-derived undo.
- Prompt-injection scan (fail-closed → 422).
- Rate limit (429 after burst); hard caps on cells / tokens / cost.
- Provider & Hermes secrets server-side; raw prompt/context/snapshot logging off.

## How to run
```bash
cd backend
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[test]"
cp .env.example .env
uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
```
Enable Hermes: set `HERMES_ENABLED=true`, `HERMES_BASE_URL=http://127.0.0.1:4012/v1`,
`HERMES_API_KEY=<valid key>`, `ENABLED_PROVIDER_TARGETS=fake,hermes`.
